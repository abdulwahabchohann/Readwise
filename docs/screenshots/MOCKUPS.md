## Screenshot Naming Convention

When taking screenshots, use this naming:

```
install-step-1-clone.png          - Git clone step
install-step-2-venv.png           - Virtual environment setup
install-step-3-dependencies.png   - Dependencies installation
install-step-4-env-config.png     - Environment configuration
install-step-5-database.png       - Database setup
install-step-6-running.png        - Server running

ui-dashboard.png                  - Main dashboard
ui-book-detail.png                - Book detail page
ui-recommendations.png            - Recommendations page
ui-mobile-dashboard.png           - Mobile view
ui-login.png                      - Login page
ui-profile.png                    - User profile
ui-reading-list.png               - Reading list page
```

## Where to Place Screenshots

After taking screenshots, place them in:
```
docs/screenshots/
├── install-step-1-clone.png
├── install-step-2-venv.png
├── install-step-3-dependencies.png
├── install-step-4-env-config.png
├── install-step-5-database.png
├── install-step-6-running.png
├── ui-dashboard.png
├── ui-book-detail.png
├── ui-recommendations.png

```

Then update README.md to reference actual images:
```markdown

```
