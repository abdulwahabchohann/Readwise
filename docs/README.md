## Adding Media Files

1. **Screenshots**: Use .png or .jpg format, 1280x720 or 1920x1080 recommended
2. **Diagrams**: Use .png for raster or .svg for vector formats
3. **GIFs**: Keep file size under 5MB, 15-30 seconds duration
4. **Videos**: Use .mp4 format, H.264 codec, 1080p recommended

## Naming Convention

- Use lowercase with hyphens: `my-screenshot.png`
- Be descriptive: `dashboard-recommendations-page.png`
- Include step numbers for sequences: `install-step-1.png`

## Updating README

When adding new media:
1. Place file in appropriate folder
2. Update the main [README.md](../README.md) with correct file path
3. Replace `[Screenshot]` placeholders with actual file references

Example:
```markdown
![Dashboard Screenshot](docs/screenshots/dashboard.png)
```

## Media Requirements

### Screenshots
- Clear visibility of UI elements
- Include browser/app UI
- Highlight important features
- Proper lighting/contrast

### Diagrams
- Clean, professional design
- Clear labels and legends
- Use consistent colors
- High resolution

### GIFs/Videos
- 1-2 seconds per action
- Smooth transitions
- Include captions if needed
- Keep file size optimized
